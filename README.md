# 📚 EbookStore – Java Web Application

EbookStore is a Java-based web application that allows users to browse, view, and manage books in an online store. The system provides features such as user authentication, book management, shopping cart functionality, and contact support.

---

## 🚀 Features

- User Registration and Login
- Browse Available Books
- View Book Details
- Add Books to Cart
- Contact Form for Queries
- Admin Book Management (Add / Edit / Delete)

---

## 🛠 Technologies Used

- Java
- JSP (Java Server Pages)
- Servlets
- HTML / CSS
- JDBC
- MySQL
- Apache Tomcat

---

---

## ⚙️ How to Run the Project

1. Install Java JDK
2. Install Apache Tomcat Server
3. Deploy the `EbookStore.war` file in Tomcat webapps folder
4. Start the server
5. Open browser and go to:

http://localhost:8080/EbookStore
